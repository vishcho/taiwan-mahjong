# 直版手機視覺提案

已定版（2026-09-11）：**B 配色 × C 排版**，作為後續 Vue 3 實作的視覺基準。[定版預覽](selected.html)・[手機截圖](mobile-selected.png)。保留 C 的資訊順序、大數字與張數條，套用 B 的墨綠桌面、米色結果卡與暖金重點色。

開啟 [互動預覽](index.html)，或直接查看 [三版比較圖](comparison.png)。手機可點「手機全螢幕預覽」，依序切換 A / B / C。

| 版本 | 方向 | 手機截圖 |
|---|---|---|
| A 清爽工具 | 淺色留白，先看最佳捨牌 | [A](mobile-a.png) |
| B 經典牌桌 | 墨綠桌面與米色牌，先看手牌 | [B](mobile-b.png) |
| C 深色數據 | 高對比數字與受入張數條 | [C](mobile-c.png) |

三版使用相同固定盤面：17 張時打九萬，聽三索、六索，共剩 7 張。可操作摸牌前／後切換、輸入區域、牌種、選牌、還原與拆解抽屜；點牌只展示選取效果，不會改變示例盤面或重新分析。

這是獨立 HTML / CSS / JavaScript 視覺原型，後續依整合版實作 Vue 3 元件與分析引擎。牌面為自製 SVG，不依賴外部字型或網路資源。

如需透過本機網址預覽，在 repo 根目錄執行：

```bash
python3 -m http.server 4173 --bind 127.0.0.1 --directory output/visual-directions
```

再開啟 `http://127.0.0.1:4173`。
